# Tushar Soni — Portfolio

Static, GitHub Pages-ready portfolio.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive design
- `script.js` — scroll reveal, cursor and navigation interactions
- `assets/resume.pdf` — current resume

## Deploy on GitHub Pages
1. Create/open your GitHub repository.
2. Replace the old site files with these files.
3. Commit and push to `main`.
4. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
5. Open the generated Pages URL.

The site uses no Node.js, npm or build step.
